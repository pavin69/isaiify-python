# ISAIIFY — "Your Music. Your World." 🎵

Spotify-inspired dark-themed Music Streaming App with Tamil & English songs.
Built with Python (Flask) backend + high-fidelity responsive frontend.

---

### 🚀 Quick Start in VS Code (Takes 10 Seconds)

1. Open **VS Code**.
2. Go to **File → Open Folder...** and select:
   ```text
   C:\Users\acer\.gemini\antigravity\scratch\isaiify-python
   ```
3. Open a terminal in VS Code (**Terminal → New Terminal** or press `Ctrl + ~`).
4. Run the app:
   ```bash
   python app.py
   ```
5. Click the link that appears in your terminal:
   👉 **http://127.0.0.1:5000**
   *(or hold `Ctrl` and click the link)*.

---

### 📱 Want to open it on your Android Phone via Wi-Fi?
Make sure your phone and PC are connected to the same Wi-Fi:
1. In your PC's terminal, find your PC's local IP address (`ipconfig`).
2. On your phone's browser (Chrome), open:
   ```text
   http://YOUR_PC_IP:5000
   ```
   Example: `http://192.168.1.10:5000`
3. Enjoy ISAIIFY on your phone instantly!
